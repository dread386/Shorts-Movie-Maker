# 🎬 Shorts Movie Maker (v1.2.0)

> **長尺動画から AI が見どころを自動検出し、8区画グリッド分割（マルチスロット）・音声フック読み上げ・9:16サムネイル・テロップ字幕付きショート動画を一括生成するローカル Web アプリケーション**

## 🌟 主な機能 (Features)

1. **📐 8区画グリッド（A〜H）× 縦型マルチスロット分割マッピング [v1.2.0 新機能]**:
   - 元の横動画（16:9）を4×2の計8区画（A〜H）にグリッド定義。
   - 縦動画のレイアウト（**上下2分割 / 上中下3分割 / 4段分割 / 2×2タイル / 左右2分割**）を選択し、各スロットに好きな区画（A:左手上、F:ピッキング手元、C:顔、ワイド区画など）を自由に配置可能！
   - 1本の横動画からまるで**マルチカメラで撮影したかのようなプロ仕様のマルチアングル動画**を全自動生成。

2. **🎙️ 冒頭タイトル読み上げ（音声フック）＆ スマートオーディオダッキング**:
   - **Style-BERT-VITS2 連携**: ローカルのボイスモデル（`my_voice` / 自分の声、`tsukuyomi-chan`、`jvnv-M1-jp` 等）でタイトル・フックを感情豊かに読み上げ。
   - **edge-tts ハイブリッド対応**: 超自然なクラウド音声（Nanami、Keita、Naoki等）へのシームレスな自動フォールバック。
   - **スマートダッキング**: ナレーションが流れている冒頭区間だけ演奏/BGM音量を自動で約30%に下げ、音声終了後にスムーズに100%復帰。

3. **🖼️ 高CTR 9:16 専用サムネイル（アイキャッチ）自動生成**:
   - 代表フレームを高画質抽出し、極太バナー＋テロップを合成した **1080x1920 高解像度 PNG サムネイル** を自動生成。
   - ワンクリック個別ダウンロードおよび一括ZIP同梱に対応。

4. **💡 上部スマートバナー（複数行自動改行 ＆ 文字サイズ調整）**:
   - 長文フック（20文字以上）でも画面幅（920px）に合わせて自動折り返し＆フォントサイズ自動調整。
   - 文字サイズ（特大 64px / 大 56px / 中 50px 推奨 / 小 42px）選択に対応。
   - 配色プリセット（黄帯×黒背景 / 赤帯×黒背景 / シンプル白枠）対応。

5. **AI ハイライト自動選定 (Gemini API 連携)**:
   - Whisperで文字起こしされたタイムスタンプ付きテキストから、山場・サビ・フックを自動検出。
   - **3つのAPIキー自動ローテーション**: レート制限時も自動で次のキーへ切り替えてリトライ。
   - **ルールベース自動フォールバック**: APIキー未設定時でも、発話・音響密度から自動切り出し。

6. **ショート動画の最適尺（10秒 / 15秒 / 20秒 / 30秒）選択**:
   - 平均視聴時間（15秒前後）にジャストフィットした黄金尺で、2分前後の動画からも 4〜6 本のショートを重複なく確実に生成。

7. **アプリ内 字幕＆バナーエディタ（即時再反映） ✏️🔄**:
   - ブラウザ上で Whisper の誤字・聞き間違いや上部バナー文言をタイムスタンプごとに入力修正。
   - ボタン1つで**数秒で動画・音声・サムネイルに再反映**され、プレビューとSRTが即座に更新。

## 🏗️ 8区画グリッド分割システム (Grid Segmentation)

```
【入力: 横動画 1920×1080 (8分割)】
  ┌────────────┬────────────┬────────────┬────────────┐
  │     A      │     B      │     C      │     D      │ (上段 y=0..540)
  │  (左手上)  │  (中左上)  │ (中右上・顔)│  (右上)    │
  ├────────────┼────────────┼────────────┼────────────┤
  │     E      │     F      │     G      │     H      │ (下段 y=540..1080)
  │  (左手下)  │ (ピッキング)│(ボディ/アンプ)│ (右下)    │
  └────────────┴────────────┴────────────┴────────────┘
        │
        │ 各スロットに A〜H（またはワイド区画）をマッピング
        ▼
【出力: 縦動画 9:16 (1080×1920)】
 [上下2分割 (ギター推奨)]     [上中下3分割]          [2×2 タイル]
 ┌──────────────────────┐   ┌──────────────────┐   ┌────────┬────────┐
 │ Slot 1 (上: A 左手)   │   │ Slot 1 (上: C 顔) │   │ Slot 1 │ Slot 2 │
 ├──────────────────────┤   ├──────────────────┤   ├────────┼────────┤
 │ Slot 2 (下: F ピック) │   │ Slot 2 (中: A 左手)│   │ Slot 3 │ Slot 4 │
 └──────────────────────┘   ├──────────────────┤   └────────┴────────┘
                            │ Slot 3 (下: F ピック)│
                            └──────────────────┘
```

## 🚀 クイックスタート (起動方法)

### 方法 1: ダブルクリック起動 (macOS)
1. フォルダ内の **`起動.command`** をダブルクリック。
2. 自動的にブラウザが立ち上がります（`http://localhost:5175`）。

### 方法 2: ターミナルから起動
```bash
# 依存ライブラリのインストール
pip3 install -r requirements.txt

# サーバー起動
python3 app.py
```
ブラウザで `http://localhost:5175` にアクセスしてください。
