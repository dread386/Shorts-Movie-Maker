# 🎬 Shorts Movie Maker (v1.1.0)

> **長尺動画から AI が見どころを自動検出し、音声フック読み上げ・9:16サムネイル・テロップ字幕付きショート動画を一括生成するローカル Web アプリケーション**

## 🌟 主な機能 (Features)

1. **🎙️ 冒頭タイトル読み上げ（音声フック）＆ スマートオーディオダッキング [v1.1.0 新機能]**:
   - **Style-BERT-VITS2 連携**: ローカルのボイスモデル（`my_voice` / 自分の声、`tsukuyomi-chan`、`jvnv-M1-jp` 等）でタイトル・フックを感情豊かに読み上げ。
   - **edge-tts ハイブリッド対応**: 超自然なクラウド音声（Nanami、Keita、Naoki等）にも対応。
   - **スマートダッキング**: ナレーションが流れている冒頭区間だけ動画本体の演奏/BGM音量を自動で約30%に下げ、音声終了後にスムーズに100%復帰（スワイプ離脱を激減）。

2. **🖼️ 高CTR 9:16 専用サムネイル（アイキャッチ）自動生成 [v1.1.0 新機能]**:
   - 代表フレームを高画質抽出し、極太バナー＋テロップを合成した **1080x1920 高解像度 PNG サムネイル** を自動生成。
   - ワンクリック個別ダウンロードおよび一括ZIP同梱に対応。

3. **💡 上部スマートバナー（複数行自動改行 ＆ スケーリング） [v1.1.0 新機能]**:
   - 長文フック（20文字以上）でも画面幅（920px）に合わせて自動折り返し＆フォントサイズ自動調整。
   - 配色プリセット（黄帯×黒背景 / 赤帯×黒背景 / シンプル白枠）対応。

4. **AI ハイライト自動選定 (Gemini API 連携)**:
   - Whisperで文字起こしされたタイムスタンプ付きテキストから、山場・サビ・フックを自動検出。
   - **3つのAPIキー自動ローテーション**: レート制限時も自動で次のキーへ切り替えてリトライ。
   - **ルールベース自動フォールバック**: APIキー未設定時でも、発話・音響密度から自動切り出し。

5. **ショート動画の最適尺（10秒 / 15秒 / 20秒 / 30秒）選択**:
   - 平均視聴時間（15秒前後）にジャストフィットした黄金尺で、2分前後の動画からも 4〜6 本のショートを重複なく確実に生成。

6. **9:16 縦型自動クロップ**:
   - **背景ぼかしパディング (`blur_pad`)**: 横型動画を中央にフル配置し上下をぼかし背景で埋める（ギター演奏や手元が見切れない推奨モード）。
   - **左手・指板フォーカス (`left_crop`)**: ギターの運指・ネック寄りを縦型に切り抜く。
   - **中央固定クロップ (`center_crop`)**: 一般的な人物トーク向け。

7. **アプリ内 字幕＆バナーエディタ（即時再反映） ✏️🔄**:
   - ブラウザ上で Whisper の誤字・聞き間違いや上部バナー文言をタイムスタンプごとに入力修正。
   - ボタン1つで**数秒で動画・音声・サムネイルに再反映**され、プレビューとSRTが即座に更新。

## 🏗️ システム構成 (Architecture)

```
[動画ファイル (16:9)]
       │
       ▼
  ① 音声抽出 (FFmpeg)
       │  audio.wav
       ▼
  ② 文字起こし (Whisper AI: 幻覚除去フィルター適用)
       │  タイムスタンプ付きセグメント
       ▼
  ③ ハイライト判定 (Gemini API: 10s/15s/20s 抽出)
       │  開始・終了タイムスタンプ
       ▼
  ④ 縦型クロップ切り出し (FFmpeg: 9:16 / 1080x1920)
       │
       ├─► 🎙️ 音声フック合成 (Style-BERT-VITS2 / edge-tts) & ダッキング
       │
       ├─► ⑤ テロップ字幕 & スマートバナー焼き込み (Pillow + FFmpeg)
       │
       └─► 🖼️ 9:16 高CTR サムネイル生成 (1080x1920 PNG)
       │
       ▼
  [完成ショート動画 (.mp4), サムネイル (.png), 字幕データ (.srt)]
```

## 🚀 クイックスタート (起動方法)

### 方法 1: ダブルクリック起動 (macOS)
1. フォルダ内の **`起動.command`** をダブルクリック。
2. 自動的にブラウザが立ち上がります（`http://localhost:5175`）。

### 方法 2: ターミナルから起動
```bash
# 依存ライブラリのインストール
pip3 install -r requirements.txt

# サーバー起動
python3 app.py
```
ブラウザで `http://localhost:5175` にアクセスしてください。
